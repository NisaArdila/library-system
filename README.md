# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository
2. Masuk ke folder project
3. Jalankan `composer install`
4. Konfigurasi file `.env`
5. Buat database `library-system`
6. Jalankan `php artisan migrate`
7. Jalankan `php artisan serve`
8. Buka aplikasi melalui browser:
http://127.0.0.1:8000
